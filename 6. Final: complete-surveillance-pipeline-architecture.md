# Complete 25–100 Camera Residential Security Surveillance Architecture

A high-throughput, low-latency computer vision pipeline built to ingest **25 to 100 IP camera feeds** simultaneously, perform **Detection → Tracking → Conditional Recognition**, and dispatch real-time alerts to a **Django** management dashboard.

---

## 1. End-to-End System Design Flow

## 2. Step-by-Step Pipeline Execution

### Step 1: Dual-Stream Ingestion & Hardware Decode
* **Dual RTSP Ingestion:** Every IP camera exposes two streams:
  * **Sub-Stream (`720p` @ `10–15 FPS`):** Used for continuous person detection and tracking across all 25–100 cameras.
  * **Main Stream (`1080p` / `4K`):** Pulled on demand only when an alert or face capture triggers, saving bandwidth and compute.
* **GPU Video Decoding (`NVDEC`):** Streams are decoded directly on the GPU's dedicated NVDEC hardware chips via **NVIDIA DeepStream (GStreamer)** or **FFmpeg (`h264_cuvid` / `hevc_cuvid`)**, preventing CPU saturation.

### Step 2: Dynamic Batching & Person Detection
* **Frame Batching:** Decoded frames are buffered and grouped into batches of **16 to 32 frames**.
* **NMS-Free Detection (`RF-DETR` / `RT-DETRv2`):** A single batched **TensorRT FP16** inference pass generates tight person bounding boxes (`[x1, y1, x2, y2, confidence]`).
  * **Primary Choice (`RF-DETR-S` / `RF-DETR-M`):** Best overall bounding box precision, stronger handling of partial occlusions and night/IR footage via its DINOv2 backbone.
  * **Wide-Angle Perimeter Choice (`RT-DETRv2-M`):** Ideal for high-mounted outdoor cameras capturing tiny, distant figures across lawns or driveways.

### Step 3: Multi-Object Tracking & Redis State Lookup
* **Tracker Assignment (`NvDCF` / `ByteTrack`):** Bounding boxes feed directly into the tracker to assign a persistent `track_id` per camera stream on every frame.
* **Redis Cache Lookup:** The worker checks Redis (`cam:{camera_id}:track:{track_id}`) to verify if the tracked person already has a resolved identity.

### Step 4: Conditional Recognition (Async Worker Path)
* **Cache Hit (Fast Path):** If an identity is already stored in Redis (e.g., `"Family - Arjun (0.81)"`), the pipeline skips all facial recognition models and carries the name forward on the bounding box.
* **Cache Miss (Recognition Path):** If `track_id` is new or unresolved:
  1. **Face Detection & Alignment (`SCRFD`):** Crops the upper body/head region and extracts 5-point facial landmarks (`scrfd_10g`) to produce an aligned `112x112` face image.
  2. **Feature Extraction (`ArcFace` / `AdaFace`):** Computes a 512-dimensional face embedding (`w600k_r50` or `ir50`).
  3. **Vector Search (`FAISS`):** Matches the 512-d vector against enrolled family, staff, and frequent visitor embeddings in under `1 ms` using cosine similarity.
  4. **Identity Caching:** Verified matches (`score >= 0.60`) are cached in Redis with a **30-second TTL**. Unmatched or turned-away faces receive a **2-second retry TTL** so recognition automatically re-attempts when the person turns toward the camera.

### Step 5: Spatial Zone Rules & Dashboard Dispatch
* **Polygon & Line Zones:** Tracked coordinates are evaluated against virtual perimeter zones (front gate, driveway, backyard, restricted rooms).
* **Cooldowns & Alerts:** Redis cooldown keys prevent duplicate alert spam while a person remains in frame. Events (camera ID, identity, confidence, high-res snapshot path, timestamp) are stored in **PostgreSQL** and streamed live to your **Django Channels (WebSocket)** dashboard and mobile push/SMS services.

## 3. Complete Model Stack Summary

| Pipeline Stage | Selected Model / Tool | Role & Advantage |
| :--- | :--- | :--- |
| **Video Decoding** | **NVIDIA NVDEC** (DeepStream / GStreamer) | Offloads 25–100 H.264/H.265 RTSP decodes directly to GPU silicon. |
| **Person Detection** | **RF-DETR** (`S` / `M`) or **RT-DETRv2** (`M`) | Batched TensorRT FP16 inference; NMS-free transformer; **Apache 2.0 license**. |
| **Object Tracking** | **NVIDIA NvDCF** or **ByteTrack** | Maintains persistent `track_id` across frames with minimal overhead. |
| **Face Alignment** | **SCRFD** (`scrfd_10g` ONNX/TensorRT) | Fast, accurate face detection and 5-point landmark alignment on person crops. |
| **Face Recognition** | **ArcFace (`w600k_r50`)** / **AdaFace (`ir50`)** | Generates 512-d facial embeddings resilient to lighting and angle shifts. |
| **Vector Matching** | **FAISS** + **Redis** | Sub-millisecond identity lookup in FAISS paired with Redis TTL identity caching. |
| **Backend & UI** | **Django + Channels + PostgreSQL** | Real-time WebSocket alerts, camera health monitoring, and searchable event logs. |

## 4. Why YOLO Was Replaced in This Architecture

In a 25–100 camera production deployment, **YOLO is completely replaced** by transformer detectors and dedicated face models for performance, licensing, and architectural efficiency:

| Previous YOLO Component | Replacement in This Stack | Why the Replacement Is Better at 25–100 Cameras |
| :--- | :--- | :--- |
| **Person Detection** (`YOLOv12`) | **RF-DETR** or **RT-DETRv2** | **1. No NMS Bottleneck:** YOLO relies on Non-Maximum Suppression (NMS), which creates latency spikes across large multi-camera batches. RF-DETR is end-to-end NMS-free.<br>**2. Apache 2.0 License:** Avoids Ultralytics AGPL-3.0 licensing restrictions for commercial or multi-site deployments.<br>**3. Stronger Occlusion Handling:** DINOv2 backbone yields tighter boxes in low light and partial occlusion. |
| **Face Detection** (`YOLOv12-Face`) | **SCRFD** (`scrfd_10g`) | **Purpose-Built Alignment:** SCRFD is specifically engineered for fast face detection and 5-point landmark alignment on cropped regions, running lighter and more accurately than a general-purpose YOLO detector. |
| **Tracking Wrapper** (`Ultralytics ByteTrack`) | **NVIDIA NvDCF** or standalone **ByteTrack** | **Hardware Offload:** NvDCF runs natively inside DeepStream on GPU/VIC hardware without tying stream orchestration to a single-stream Python loop. |

> **Optional Hybrid Note:** If you have an existing custom-trained **YOLOv12** model (such as a specialized weapon or package detector), it can still be plugged into **Stage 1** alongside or in place of RF-DETR, as both consume batched frames and output standard `[x1, y1, x2, y2, confidence]` coordinates.

## 5. Reference Worker Implementation (Python)

```python
import redis
import faiss
import numpy as np

# Redis connection for track_id -> identity state caching
cache = redis.Redis(host="localhost", port=6379, decode_responses=True)

def process_camera_stream(
    camera_id: str,
    frame: np.ndarray,
    detector,
    tracker,
    face_detector,
    recognizer,
    faiss_index,
    id_map: dict,
    similarity_threshold: float = 0.60,
):
    # 1. PERSON DETECTION (RF-DETR / RT-DETRv2 TensorRT)
    person_boxes = detector.infer(frame)  # [x1, y1, x2, y2, conf]

    # 2. MULTI-OBJECT TRACKING (NvDCF / ByteTrack)
    tracks = tracker.update(person_boxes)  # [x1, y1, x2, y2, track_id]

    frame_events = []
    for x1, y1, x2, y2, track_id in tracks:
        cache_key = f"cam:{camera_id}:track:{track_id}"
        identity = cache.get(cache_key)

        # 3. CONDITIONAL FACE RECOGNITION (Runs only on cache miss)
        if identity is None:
            person_crop = frame[max(0, int(y1)):int(y2), max(0, int(x1)):int(x2)]
            aligned_face = face_detector.detect_and_align(person_crop)

            if aligned_face is not None:
                embedding = recognizer.get_embedding(aligned_face).astype("float32")
                faiss.normalize_L2(embedding)

                scores, indices = faiss_index.search(embedding, k=1)
                best_score = float(scores[0][0])
                best_idx = int(indices[0][0])

                if best_score >= similarity_threshold and best_idx in id_map:
                    identity = f"{id_map[best_idx]} ({best_score:.2f})"
                    cache.setex(cache_key, 30, identity)  # Lock identity for 30s
                else:
                    identity = "Unknown"
                    cache.setex(cache_key, 2, identity)   # Retry in 2s if angle improves
            else:
                identity = "Scanning..."

        frame_events.append({
            "camera_id": camera_id,
            "track_id": int(track_id),
            "bbox": [float(x1), float(y1), float(x2), float(y2)],
            "identity": identity,
        })

    return frame_events
```
